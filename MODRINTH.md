Fatfingert stops you from wrecking your own inventory by accident. It lets you reserve specific hotbar slots and the offhand slot for specific items, so a mistimed key press or a rushed click can't swap, drop, or overwrite the item that's supposed to be there. If an input would put the wrong item into a slot you've reserved, that single input is simply cancelled — nothing else happens.

This covers the moments that actually cost you: pressing F to swap hands and grabbing the wrong item back, shift-clicking a chest and having a reserved hotbar slot get filled with junk, or dragging something into the slot your totem or shield is supposed to live in. Fatfingert catches all of it before it happens, in any inventory screen — your own inventory, chests, shulker boxes, anywhere.

Rules are organized into presets, so you can keep different setups for different situations and switch between them with one click. A preset built for reserving your offhand for a totem is included by default, and a "none" preset is there for stock behavior. You can also create, rename, and delete your own presets from the in-game menu — no config editing required, though the config file is plain, readable JSON if you'd rather edit it by hand.

Everything is controlled through a menu opened from a button in your inventory screen, or from Mod Menu if you have it installed (optional, not required). From there you can turn the whole mod on or off, switch presets, choose which slots are reserved and for which items, and toggle two extra behaviors: Strict Shift-Click, which also blocks shift-clicks that could land an item in a reserved slot, and Lock Contents, which stops a reserved item from being taken back out of its slot at all.

Fatfingert is client-side only and does not need to be installed on a server. It does not automate, inject, or send any input on your behalf — it only ever cancels an input you already made, the same way a "delete this file?" prompt stops a click rather than making one for you. It does not read or send any data anywhere; all settings are saved to a local config file in your own game folder. It requires Fabric API and, out of the box, will reserve your offhand slot for a totem of undying — switch to the "none" preset if you'd rather start from a blank slate.
